# OpenCode — AI-Assisted Embedded Software Development Environment

AI should not merely generate code.

It should help engineers understand complex systems, explore architectural decisions, identify problems, reason about hardware and software interactions, and build reliable solutions.

The objective is to create an AI engineering environment that becomes more capable, structured, and useful over time.

The repository structure will evolve as the environment grows.

```text
opencode/
├── agents/          # Specialized AI agents
├── commands/        # Reusable workflows and commands
├── skills/          # Engineering knowledge and reusable skills
├── rules/           # Global engineering instructions
├── tools/           # Custom tools and integrations
└── README.md        # Project overview and documentation
```

---

*Built incrementally. Designed for engineering. Evolving with AI.*
